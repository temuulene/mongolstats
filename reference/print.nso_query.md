# Print an nso_query object

Displays a human-readable summary of the query, including the table
identifier and the first few dimension selections.

## Usage

``` r
# S3 method for class 'nso_query'
print(x, ...)
```

## Arguments

- x:

  An `nso_query` object created by
  [`nso_query()`](https://temuulene.github.io/mongolstats/reference/nso_query.md).

- ...:

  Additional arguments passed to print methods (ignored).

## Value

`x`, invisibly.
